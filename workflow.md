# Workflow and milestones

| Milestone | Evidence |
|---|---|
| 1. Scope and data audit | [Data audit](docs/data-audit.md), four-question scope, model and implementation reviews |
| 2. Baseline | Reproducible analyses and first integrated scenario results |
| 3. Validation | Independent checks, grouped validation, and sensitivity results |
| 4. Paper and reproduction | Evidence review, English manuscript, and clean-checkout reproduction |

The project lead integrates the work and maintains the release sequence. Model design, implementation readiness, results, and paper claims receive independent review. Approval to implement the proposed baseline was recorded in the project conversation.
