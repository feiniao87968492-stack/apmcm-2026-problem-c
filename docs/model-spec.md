# Formal analysis specification

Frozen before the integrated production run. Earlier Q1–Q3 component smoke runs used the real data, so this is a versioned analysis freeze following feasibility checks. The six-feature decision follows the attachment's missingness pattern. The analysis uses the approved baseline and evaluates the listed sensitivities without selecting them by their results.

| Question | Fixed choice and assumption | Rationale |
|---|---|---|
| Q1 features | Use Duration, F01, Fpeak, Q25, Q50 and Q75 for the primary classifier. Describe F02 and PulseRate where measured. Use F02 availability as a diagnostic and fold-median pulse imputation as a sensitivity. | F02 is present only for two-voice calls. Pulse rate is absent in all 44 flat calls and in 10 other recordings. Using universally observed features limits dependence on the recording schema. |
| Q1 inference | Use available observations in Kruskal–Wallis and Mann–Whitney tests, with separate Holm corrections for omnibus and pairwise families. Evaluate a standardized L2 multinomial classifier and fold-majority baseline using five stratified date-by-location grouped folds. Use pooled macro F1, confusion counts, group bootstrap of fixed out-of-fold predictions and 40 test-fold permutations per feature. | Macro F1 gives all three call types equal weight. Holding recording groups out avoids within-session overlap. The rank tests describe sample-level contrasts and can be affected by within-group dependence. |
| Q2 fit | Compute observed means per acoustic representation and distance, clip the weighted mean to [0,1], fit downward isotonic regression and interpolate in log distance over 4–256 m. Use equal weights as primary. Use (0.45,0.45,0.10), (0.25,0.25,0.50) and unconstrained interpolation as checks. | The log scale follows the doubled distance design. Average signal quality is expected to decline with distance, although individual readings fluctuate. Equal weighting avoids estimating perceptual importance from an unrelated behavioral experiment. |
| Q2 uncertainty | Use fixed thresholds 0.40, 0.50, 0.60 for potential, standard and reliable recognition and 0.70 as a stricter scenario. Independently resample complete wide rows by representation. Repeat with aligned-row draws when missingness masks match. At support limits report bounds. | Thresholds turn signal similarity into an operational range. Distance observations stay together within each sampled row. The attachments lack acquisition identifiers, so both interval conventions are conditional on their row-resampling assumptions. |
| Q3 behavior | Encode head, vocal and approach with bits 1, 2 and 4. Compare paired any-response rates descriptively. Fit a standardized L2 multinomial model (C=1) to mask using assigned call, stimulus, interaction, context, log(1+distance) and log(1+group size). Validate in five expID-grouped folds against pooled training frequencies and resample pairs intact. | The model accounts for co-occurring behaviors using one probability distribution. Ninety pairs differ in playback distance, so each row retains its recorded covariates. Adjusted stimulus contrasts use identical covariates. Regularization stabilizes sparse behavior combinations. |
| Q3 latency | For each behavior fit ridge regression (alpha=5) to log(1+seconds) among observed responders, with a Gaussian residual model on that scale. Report response probability, conditional median and sample support at 50, 100 and 150 m and eight birds. Average contexts using empirical frequencies and weight the conditional latency mixture by event probability. A stratum with no observed latency has no estimated median. Flag fewer than five observed latencies within 25 m as sparse. | The transformation keeps observed zero onsets. The two outcomes address different questions about behavior. The support flag gives the reader local sample context. |
| Q4 integration | Combine fidelity and standardized natural-response probability by multiplication. Use the common 20–150 m domain, a 0.5 m grid, median group size eight and empirical context weights. Use the final above-cutoff location to interpolate the sustained crossing at 50% of the call's clean index at 20 m. Keep that reference fixed across scenarios. Check 40% and 60%, component-only models and Q2 weight choices. | A call should retain signal and elicit behavior to score strongly. A relative clean reference measures retention within a call type, so absolute index values also accompany radius comparisons. Common support keeps comparisons within all three call domains. |
| Q4 scenarios | Gate the index below fidelity thresholds 0.50, 0.60 and 0.70. Evaluate uniform losses of 5%, 10%, 15% and 20%. Apply the resulting retention to the positive natural-response excess over its matched control prediction. For expected counts assume 25%, 50% or 75% of eight birds respond when any response occurs. Pair Q2 and Q3 draws by index from separately seeded analyses. | These transparent perturbations isolate how the operational result depends on recognition, retention and the group-to-individual assumption. The two independent sources of data give a conditional combined uncertainty assessment. |

Python uses seed 20261126 for Q1, +1 for Q2 and +2 for Q3, with 300 draws per analysis. All reported intervals use 2.5th and 97.5th percentiles. Figures carry CSV values and JSON metadata. Model terms and assumptions are fixed here before the production results are used to draft conclusions.

Q1 feasibility explored allocations using labels and group counts only, including a StratifiedGroupKFold seed scan and a count-balanced permutation search. No improvement models or outcome comparisons were run before this freeze.

- **Q1.** Estimate three-class macro F1 and per-class recall on held-out recording groups, scoring 108 recordings from 16 date-by-location groups. For the shared comparison fix five test folds. Index the lexicographically sorted unique strings Date + " | " + Location from zero. Fold memberships are [1,15,12,5], [3,7,0], [8,10,9], [2,6,11], [13,14,4]. Compare training-fold majority, training-fold standardized L2 logistic (C=1, max_iter=1000), and unweighted random forest (200 trees, max_depth=3, min_samples_leaf=4, seed 20261126). Both classifiers use the same six complete features. Keep pulse-rate training-fold median imputation and F02 availability as logistic/availability sensitivities and preserve the published historical comparison. Use 300 paired bootstrap resamples of the 16 groups with replacement from the fixed OOF predictions (seed 20261126), and percentile intervals for F1 difference and individual recalls. Adopt forest as the preferred shared-feature classifier only when its pooled F1 exceeds both logistic and majority and the lower bound of its paired forest-minus-logistic interval is above zero. The balanced comparison estimates performance for this grouped design. Its intervals condition on fitted OOF predictions, and downstream models use measured labels.
- **Q2.** Retain the published equal-weight isotonic similarity model, the 4–256 m design, 0.40/0.50/0.60 primary thresholds and the 0.70 sensitivity. Audit point ranks, marginal intervals, curves and alternative weights/fits from the published results. Keep seed 20261127 and 300 draws in reproduction. The resampling unit is the whole wide row within each representation, preserving distance dependence within that row. - **Q3.** Estimate predictive value beyond stimulus type under the original five expID-grouped folds, which hold out 28/28/28/28/27 intact pairs. Keep the 300 intact-pair bootstrap draws at seed 20261128. Audit observed trials, events and available conditional latencies by stimulus, assigned call and behavior within inclusive 25 m of 50, 100 and 150 m, counting each window on its own. - **Q4.** Estimate point indices and sustained operational crossings on the existing 0.5 m grid over 20–150 m, combining Q2 fidelity and Q3 standardized group response at eight birds and empirical context weights. Compare clean indices over the full grid and summarize matched point values and paired call differences at 20, 50, 100 and 150 m. Retain the original call-specific threshold 0.5 times clean index at 20 m. Add a common threshold of 0.5 times the equally weighted mean of the three clean indices at 20 m, which holds all calls to a single absolute target while preserving the original half-retention convention at the aggregate level. For each threshold compare clean and losses of 5/10/15/20%. At loss L, compare the acoustic-only index F(1-L)p_nat with the coupled index F(1-L)[p_nat-L max(p_nat-p_ctrl,0)]. The latter posits proportional loss of positive response excess and holds the matched control fixed. These are illustrative bounds on two specified scenarios, with no field estimate of a noise effect. Both retain the clean cutoff across scenarios and use the same 300 paired draws by index from Q2 and Q3 with the corresponding draw's clean cutoff. Report percentile intervals, support-bound counts, point ranks and above-cutoff status at 50/100/150 m. A reported ordering or site-distance conclusion is stable only across the named definitions where it agrees, with uncertainty and one-sided support bounds reported separately. Keep the existing primary relative index and contextualize any recommendation that varies with assumptions. Accept the contrast outputs if the original relative case reproduces, greater damage never increases the index, and crossings match an independent recomputation. Treat 150 m as a support limit.

## Improvement round 2 freeze

Reference release a0d8a74. No round-two outcome estimates or candidate fits were inspected before this freeze. Retain the round-one result files and use the same attachment inputs. All intervals use the 2.5th and 97.5th percentiles of 300 draws by default. The analysis entry point passes its existing seed and bootstrap count.

- **Q1.** Use the same 108 recordings, six complete features and fixed five date-by-location folds from round one. Compare the released standardized logistic and random forest predictions with untuned XGBoost 3.2.0 using histogram trees on CPU, 100 trees, maximum depth 2, learning rate 0.05, minimum child weight 3, L2 penalty 1, L1 penalty 0, full row and column sampling, softprob objective, one thread and seed 20261126. Use the numeric class order flat, modulated, two-voice. Score pooled macro F1 and two-voice recall. Resample the 16 recording groups in common across the three fixed out-of-fold predictions at seed 20261126. Omit draws missing any true class, as in round one. Prefer boosting only when both paired F1 intervals against logistic and forest exclude zero on the positive side and its point two-voice recall is at least that of both controls.
- **Q2.** Remove each representation in turn and weight the two remaining representations 0.5 each. Reuse the same observed means, clipping, isotonic fit and log-distance crossing over 4–256 m for 0.40, 0.50, 0.60 and 0.70. Pair all contrasts by the independent whole-row bootstrap draws from round one (seed 20261127). Report bounded radii, support flags, paired differences from full fidelity and point ordering at every threshold. The matched draws preserve within-row distance dependence. Independent acquisition units remain unknown. Keep the three-component definition unless there is external evidence for excluding a representation. Treat ordering changes as sensitivity.
- **Q3.** Retain the released five expID-grouped folds on all 139 natural/control pairs and use training-only standardization with L2 multinomial logistic (C=1, max_iter=1000) for each nested model. Compare the empirical stimulus-only comparator and a stimulus-only logistic model, then add log(1+distance), assigned-call indicators and their interactions with stimulus, and finally context indicators and log(1+group size). Use the same context coding as round one. Comparing the two stimulus-only fits isolates the estimator change. Compare each covariate block with its immediate nested predecessor and use the same log mask loss floor of 1e-12 and any-response Brier score. These scores are unweighted means over five folds. Resample whole pairs with replacement within each held-out fold at seed 20261128, keeping predictions fixed and resampling jointly across models. Call a block jointly supported only if both paired loss-difference upper bounds are below zero. Keep the existing descriptive use of the full model for standardized contrasts. Block effects are order-dependent predictive contrasts.
- **Q4.** Predict any response (binary) with standardized L2 logistic (C=1, max_iter=1000). Use the original expID folds assigned before restriction. Both models train and score on the same playback rows within 20–150 m. In a pair with one row outside support, keep the other row in its original fold. The baseline uses the full Q3 covariates across the supported rows. The augmented model adds the equal-weight isotonic propagation curve for the assigned call evaluated at the actual playback distance and its interaction with natural stimulus. The curve comes solely from independent propagation attachments Data03–Data11. Use interpolation in log distance at the exact recorded distances. Compare binary log loss and Brier as in Q3 (five-fold mean, clip the observed-outcome probability below at 1e-12, paired fold-stratified experiment bootstrap at seed 20261129). Within a fold, resample intact retained rows by experiment and weight the fold means by row count within each sampled fold. Report sample coverage, Pearson correlation of fidelity with log(1+distance) and descriptive in-sample R-squared when regressing fidelity on log(1+distance) with assigned-call indicators. Report within-call correlations. Accept predictive use of fidelity only if both paired loss-difference upper bounds are below zero. The derived covariate is a function of call type and distance. This comparison tests added predictive information under the fixed model form. Even a gain can reflect modeling of nonlinearity or call-specific slopes. Evaluate overlap with the existing distance-adjusted probability in the operational product and retain its scenario interpretation.
