# Stony Point boat-noise experiment

DataTable_analysis3.csv is the unmodified activity-budget table deposited by Andréa Thiebault at Zenodo, versioned record 23923079. The study tested airborne recordings of motor boats on wild African penguins on land near Stony Point, South Africa. The table records behavior scan counts by video, individual, exposure stratum and period. [Versioned data deposit](https://doi.org/10.5281/zenodo.23923079) · [Source study](https://doi.org/10.1016/j.scitotenv.2026.182372) · [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
